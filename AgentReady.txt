# AgentReady

> AgentReady is an AI readiness platform that scans websites and generates an AI Readiness Score (0-100). It measures how well AI engines like ChatGPT, Perplexity, Google AI Overviews, and Claude can find, understand, and cite your website content.

## Overview

AgentReady analyzes websites across 8 scoring factors using Algorithm v2.0. Each factor is weighted and combined into a single AI Readiness Score. The platform benchmarks sites against 490+ domains across 14 industries.

## Scoring Factors (Algorithm v2.0)

- **Content Quality (20%)**: Answer-first formatting, FAQ patterns, heading hierarchy, readability, and research signals.
- **Bot Access (20%)**: robots.txt configuration for AI crawlers including GPTBot, Google-Extended, ClaudeBot, and PerplexityBot.
- **Schema Markup (18%)**: JSON-LD structured data coverage, schema type diversity (Organization, Article, Product, FAQ), and validation compliance.
- **Topic Clarity (10%)**: Named entity recognition density, author attribution, E-E-A-T signals, and organizational identity.
- **AI Protocols (10%)**: llms.txt, NLWeb endpoints, MCP configuration, AI sitemaps, and structured APIs.
- **Authority & Trust (10%)**: Domain authority, backlink profile, brand mentions, and editorial trust signals.
- **Crawl Health (7%)**: XML sitemap completeness, canonical tags, redirect chains, crawl budget efficiency, and broken link prevention.
- **Speed & Performance (5%)**: Core Web Vitals including FCP, LCP, CLS, TTFB, and mobile responsiveness.

## Grade Scale

- **A+ (90-100)**: Exceptional — site is fully optimized for AI discovery and citation.
- **A (80-89)**: Excellent — strong AI readiness with minor improvements possible.
- **B+ (70-79)**: Good — solid foundation, some factors need attention.
- **B (60-69)**: Above Average — noticeable gaps in AI readiness.
- **C+ (55-59)**: Average — several areas need improvement.
- **C (45-54)**: Below Average — significant gaps in AI readiness.
- **D (30-44)**: Poor — major issues preventing AI discovery.
- **F (0-29)**: Failing — site is largely invisible to AI engines.

## API

AgentReady provides a REST API for programmatic scanning:

- `POST /api/scan` — Submit a URL for AI readiness analysis
- `GET /api/scan/:id` — Retrieve scan results by ID
- `GET /api/benchmarks` — Industry benchmark data
- `GET /api/score/:domain` — Look up scores for a previously scanned domain
